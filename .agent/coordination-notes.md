# 協調筆記 (Coordination Notes)

母 Agent 在此與該子專項溝通跨層修改的相關決策和反饋。

---

## 📝 使用說明

- 本檔案在各子專項根目錄：`.agent/coordination-notes.md`
- 母 Agent 在此提出修改建議、拒絕理由或協商意見
- 你看到反饋後，在 `AGENT_LOG.md` 中記錄理解和後續行動
- 每個記錄都應包含日期和相關申請的連結
