# QCC Helper — 需求規格書

## 1. 產品概述

**QCC Helper** 是一套協助醫院同仁執行品管圈（Quality Control Circle）活動的 Web 工具。同仁可依照品管圈十大步驟，逐步填寫表單、上傳數據、透過 AI Agent 協助分析，最終產出符合醫院繳交要求的成果報告。

## 2. 目標使用者

- 醫院各科室品管圈圈員（護理師、醫師、行政人員等）
- 品管圈圈長（負責管理進度）
- 品管中心輔導員（審核與指導）

## 3. 核心功能需求

### 3.1 專案管理

| 功能 | 說明 |
|------|------|
| 建立專案 | 輸入圈名、科別、活動期間，建立新的 QCC 專案 |
| 專案列表 | 查看所有進行中/已完成的 QCC 專案 |
| 進度總覽 | 顯示目前所在步驟、各步驟完成狀態 |

### 3.2 十大步驟 — 各步驟表單欄位與上傳需求

---

#### 步驟一：組圈

**表單欄位：**
- 圈名
- 圈徽（圖片上傳）
- 圈的意義說明
- 科別 / 單位
- 活動期間（起迄日期）
- 圈長姓名、職稱
- 輔導員姓名、職稱
- 圈員名單（姓名、職稱、角色分工）

**上傳區：**
- 圈徽圖片（PNG/JPG）

**AI Agent 協助：**
- 依科別與主題建議圈名
- 產生圈的意義說明草稿

**成果物：** 組圈登記表

---

#### 步驟二：主題選定

**表單欄位：**
- 候選主題清單（至少 3 個主題，含簡述）
- 評價項目（預設：上級政策、重要性、迫切性、圈能力、可行性，可自訂）
- 評價矩陣（每位圈員對每個主題 × 每個評價項目打分，5/3/1 分制）
- 選定主題名稱
- 選題理由（文字說明）
- 衡量指標定義（如：跌倒次數、等候時間等）

**上傳區：**
- 相關佐證資料（PDF/圖片，如：異常事件統計、投訴紀錄）

**AI Agent 協助：**
- 依候選主題產生選題理由草稿
- 自動計算評價矩陣加總與排序
- 建議衡量指標

**成果物：** 主題選定評價表、選題理由書

---

#### 步驟三：活動計畫擬定

**表單欄位：**
- 各步驟預計起迄日期
- 各步驟負責人
- 開會頻率
- 預計活動總週數

**AI Agent 協助：**
- 依總週數自動建議各步驟時程分配（建議比例）：
  - 步驟 1~6（P 階段）：佔 30%
  - 步驟 7（D 階段）：佔 30%
  - 步驟 8~9（C 階段）：佔 20%
  - 步驟 10（A 階段）：佔 10~20%
- 產生甘特圖（虛線＝預定進度、實線＝實際進度）
- 注意：「解析」與「對策擬定」不可重疊；「效果確認」與「標準化」不可重疊

**成果物：** 甘特圖、活動計畫書

---

#### 步驟四：現況把握

**表單欄位：**
- 查檢期間（起迄日期）
- 查檢項目名稱清單（即缺失類別，如：未洗手、未確認身份...）
- 查檢總數（分母）

**上傳區：**
- 原始查檢數據（CSV/Excel 檔案）
  - 格式：每列一筆紀錄，欄位包含日期、缺失類別、次數等
- 或手動輸入查檢表數據（表格介面）

**AI Agent 協助：**
- 解析上傳的 CSV/Excel，自動辨識缺失類別與次數
- 自動繪製**改善前柏拉圖**（Pareto Chart）
  - X 軸：缺失類別（依次數由高到低排列）
  - 左 Y 軸：次數
  - 右 Y 軸：累積百分比
  - 標示 80% 線
- 計算各項目佔比與累積百分比，格式如下：

  | 缺失類別 | 次數 | 累計次數 | 百分比 | 累積百分比 |
  |---------|------|---------|--------|-----------|
  | 問題 A  | 45   | 45      | 37.5%  | 37.5%     |
  | 問題 B  | 30   | 75      | 25.0%  | 62.5%     |
  | 問題 C  | 20   | 95      | 16.7%  | 79.2%     |
  | 其他    | 25   | 120     | 20.8%  | 100.0%    |

  - 項目由大到小排列，「其他」放最末
  - 項目數控制在 6~10 個以內
- 找出關鍵少數（vital few）項目（80% 線以內）
- 計算現狀值：不良次數 / 總調查次數 × 100%
- 產生現況描述文字

**成果物：** 查檢表、改善前柏拉圖、現況描述

---

#### 步驟五：目標設定

**表單欄位：**
- 現狀值（自動帶入步驟四數據：不良次數 / 總調查次數 × 100%）
- 改善重點佔比（自動帶入：柏拉圖 80% 線以內的累積百分比）
- 圈能力值（全體圈員自評，0~1 之間）
- 目標計算方式選擇：
  - 自訂目標（手動輸入）
  - 依公式計算：
    - **降低類主題**：`目標值 = 現狀值 −（現狀值 × 改善重點 × 圈能力）`
    - **提升類主題**：`目標值 = 現狀值 +（(1 − 現狀值) × 改善重點 × 圈能力）`
- 計算後目標值（自動計算或手動輸入）
- 目標設定理由（文字說明）

**AI Agent 協助：**
- 自動帶入現狀值與改善重點佔比
- 依公式計算建議目標值
- 產生目標設定說明文字（含計算過程）

**成果物：** 目標設定表（含公式計算過程）

---

#### 步驟六：解析

**表單欄位：**
- 魚骨圖主題（即要分析的問題，如「跌倒率偏高」）
- 大要因分類（預設 4M1E：人 Man、機 Machine、料 Material、法 Method、環 Environment，可自訂）
- 每個大要因下的中要因（文字輸入）
- 每個中要因下的小要因（文字輸入）
- 真因圈選（勾選哪些小要因為真因）
- 真因驗證表：
  - 小要因名稱
  - 驗證方法（文字）
  - 驗證結果（是/否為真因）
  - 佐證說明

**上傳區：**
- 真因驗證佐證資料（圖片/PDF/數據）

**AI Agent 協助：**
- 依主題建議魚骨圖各層要因
- 自動繪製魚骨圖（Fishbone Diagram）
- 建議真因驗證方法

**成果物：** 魚骨圖（特性要因圖）、真因驗證表

---

#### 步驟七：對策擬定

**表單欄位：**
- 對策清單（針對每個真因，5W1H 格式）：
  - 真因（自動帶入步驟六）
  - What：對策方案內容
  - Why：為何採此對策
  - Who：負責人
  - Where：實施地點/範圍
  - When：預計完成日
  - How：具體執行方法
- 對策評價矩陣：
  - 評價項目（預設：可行性、經濟性、效益性，可自訂）
  - 評分（5/3/1 分制，每位圈員打分）
- 採行對策標準（總分門檻）
- 採行/不採行判定

**AI Agent 協助：**
- 依真因建議對策方案
- 自動計算對策評分與排序
- 產生對策擬定說明

**成果物：** 對策擬定一覽表、對策評價表

---

#### 步驟八：對策實施與檢討

**表單欄位：**
- 每項採行對策的實施紀錄：
  - 對策名稱（自動帶入）
  - 實施日期
  - 實施前狀況描述
  - 實施後狀況描述
  - 負責人
  - 實施狀態（進行中/已完成/延遲）
  - 單項對策效果驗證（有效/無效/需修正）
  - 檢討說明

**上傳區：**
- 實施前後對比照片
- 相關文件（如：新版 SOP、教育訓練紀錄、公告等）
- 各對策的效果驗證查檢表數據

**AI Agent 協助：**
- 追蹤進度、提醒逾期項目
- 協助撰寫檢討說明

**成果物：** 對策實施檢討表

---

#### 步驟九：效果確認

**表單欄位：**
- 改善後查檢期間
- 改善後查檢總數（分母）

**上傳區：**
- 改善後查檢數據（CSV/Excel，格式同步驟四）
- 或手動輸入改善後數據

**AI Agent 協助：**
- 解析改善後數據
- 自動繪製**改善後柏拉圖**
- 自動產生**改善前後柏拉圖對比**（兩張並排）
- 計算有形成果：
  - **改善幅度**：`(改善前 − 改善後) / 改善前 × 100%`
  - **目標達成率**：`(改善前 − 改善後) / (改善前 − 目標值) × 100%`
- 產生效果確認說明文字
- 產生**無形成果雷達圖**：
  - 評估項目（預設 6~8 項，可自訂）：QCC 手法運用、溝通能力、團隊合作、問題解決能力、品質意識、責任感、積極性、和諧度
  - 全體圈員對改善前、改善後分別自評（1~5 分）
  - 雷達圖呈現改善前（虛線）vs 改善後（實線）

**成果物：** 改善後柏拉圖、改善前後對比圖、目標達成率計算表、無形成果雷達圖

---

#### 步驟十：標準化與檢討改進

**表單欄位：**
- 標準化項目清單：
  - 對策名稱
  - 標準化內容（文字）
  - 文件編號（如 SOP 編號）
  - 負責維護人
- 檢討與改進：
  - 本次活動優點
  - 本次活動待改進事項
  - 下期活動主題建議

**上傳區：**
- 標準化文件（PDF，如新版 SOP）

**AI Agent 協助：**
- 依對策內容產生 SOP 草稿
- 產生活動檢討總結
- 建議下期活動方向

**成果物：** 標準化一覽表、SOP 草稿、檢討改進表

---

### 3.3 AI Agent 通用功能

| 功能 | 說明 |
|------|------|
| 步驟引導 | 在每個步驟提供說明，告訴同仁「這步要做什麼、怎麼做」 |
| 數據分析 | 解析上傳的 CSV/Excel，自動產生統計與圖表 |
| 圖表生成 | 柏拉圖、魚骨圖、甘特圖、雷達圖等 |
| 文字生成 | 選題理由、現況描述、對策說明、檢討文字等 |
| 對話問答 | 同仁可隨時詢問品管圈相關問題 |

### 3.4 資料上傳規格

| 檔案類型 | 用途 | 格式要求 |
|----------|------|----------|
| CSV/Excel | 查檢表數據 | 須包含：日期、類別、次數等欄位 |
| PNG/JPG | 圈徽、實施照片 | 單檔 ≤ 5MB |
| PDF | 佐證文件、SOP | 單檔 ≤ 10MB |

### 3.5 成果匯出

| 匯出格式 | 內容 |
|----------|------|
| PDF 報告 | 完整十步驟成果報告（含所有圖表） |
| PPT 簡報 | 成果發表用簡報（含關鍵圖表與摘要） |
| 單步驟匯出 | 各步驟可獨立匯出為 PDF |
| 成果發表海報 | A0/A1 尺寸海報，含十步驟摘要與關鍵圖表 |

## 4. 非功能需求

| 項目 | 要求 |
|------|------|
| 響應式設計 | 支援桌面與平板瀏覽器 |
| 繁體中文 | 全介面繁體中文 |
| 資料儲存 | 自動儲存，避免填寫中途遺失 |
| 權限 | 基本帳號登入，區分圈員/圈長/輔導員角色 |
| 隱私 | 不儲存病患個資，僅處理統計數據 |

## 5. 技術架構（建議）

```
Frontend:  Next.js + TypeScript + Tailwind CSS
Backend:   Next.js API Routes
Database:  SQLite (開發) / Cloudflare D1 (部署)
AI:        Claude API (對話與分析)
Charts:    ECharts 或 Chart.js
File:      本地檔案儲存 / Cloudflare R2
Export:    jsPDF + pptxgenjs
```

## 6. 資料模型概要

```
Project (專案)
├── id, name, circle_name, department, period_start, period_end, status
├── Members[] (圈員)
│   └── id, name, title, role (圈長/圈員/輔導員)
├── Steps[] (步驟狀態)
│   └── id, step_number (1-10), status (not_started/in_progress/completed), data (JSON)
├── Uploads[] (上傳檔案)
│   └── id, step_number, file_name, file_type, file_path, uploaded_at
└── ChatHistory[] (Agent 對話紀錄)
    └── id, step_number, role, content, created_at
```

## 7. 頁面結構

```
/                        → 首頁 / 專案列表
/project/new             → 建立新專案
/project/:id             → 專案總覽（進度儀表板）
/project/:id/step/:n     → 步驟 n 的表單頁面（含 Agent 對話區）
/project/:id/export      → 成果匯出頁面
```

## 8. MVP 範圍（第一版）

第一版優先實作：
1. 專案建立與管理
2. 十大步驟的表單填寫與資料儲存
3. 步驟四（現況把握）與步驟九（效果確認）的 CSV 上傳與柏拉圖生成
4. 步驟六（解析）的魚骨圖互動編輯與生成
5. 每步驟的 AI Agent 對話協助
6. PDF 報告匯出

暫緩功能：
- PPT 匯出
- 多人即時協作
- 輔導員審核流程
- 通知與提醒系統
